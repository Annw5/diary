Дневник хранится зашифрованным в файле diary3.bin только на этом устройстве и работает без интернета. Пароль восстановить нельзя: без него файл не прочитать. В пустой дневник пускает любой пароль, он станет твоим. Оформление: HTML/CSS между <<< и >>> действует на эту и следующие записи. После входа команда «хелп» покажет все команды. ⚠ JavaScript в оформлении видит твои записи и может отправить их в интернет: вставляй только код, который понимаешь. Скрипты сами не стартуют, их включает команда «запуск». Если оформление сломалось: войди, напиши «стоп» (оформление отключится), исправь код между <<< и >>>, затем «запуск».
